# 版本恢复说明

本次从本机保留的应用、安装包和源码备份恢复了 **80 个构建版本**，从 **1.0 / build 1** 到 **1.49.15 / build 80**，构建号 1—80 连续。重复保存的应用/ZIP 副本共有 88 份；同一版本的副本不算不同版本。

## 历史提交代表什么

各历史版本从对应原始应用的 `Contents/Resources` 提取 Python、HTML、CSS 和 JavaScript 运行源码，再按版本先后建立恢复提交。它们记录“这一版已发布程序实际带了什么代码”，**不是原始开发 Git 历史**，不还原当时的提交时间、分支、逐步修改、原始作者提交或每次工作过程。

保存的应用还包含对应的原生可执行文件、图标、Info.plist 和签名。旧版 Swift 源码、各版构建脚本及测试没有完整保存，因此历史运行源码可以查看、比较和继续研究，但不能宣称每个旧版原生 app 都可从当时的完整开发源码重新编译。

最新版 `outputs/focus-quest` 是完整可编辑开发项目，包括现有 Swift 源码、规则模块、静态资源、图标、脚本和测试。独立的手机日历桥源码位于 `outputs/手机同步诊断`。

## 原始应用的保存方式

80 个版本的原始应用安装包作为 GitHub Release 附件保存，访问入口为[仓库 Releases](https://github.com/Jiang-liran/focus-quest/releases)。原应用与恢复源码分别保存，Release 安装包用于取回原始可执行程序，Git 历史用于查看和比较代码。

已有的原 ZIP 应保持字节不变；只有保留 app 目录的版本可另装入恢复 ZIP，并明确记录它是归档包装，不能把新 ZIP 声称为当年的原下载 ZIP。各版本的来源和 SHA-256 以仓库版本清单及 Release 附件说明为准。


初版包含原始 Python 后端、三个界面文件、Mac 可执行文件、图标、Plist 与签名，共 8 个文件。ZIP CRC 校验通过。

## 取回一个版本

若要直接取回原始程序，在 Releases 中下载该版本对应的 ZIP。若要取回它的运行源码，在仓库中查询标签和提交，再切换到所需版本：

```sh
git clone https://github.com/Jiang-liran/focus-quest.git
cd focus-quest
git tag --list
git log --oneline --all
git switch --detach <版本清单中的标签>
```

标签名称以最终版本清单为准。历史快照里只保留该版确认存在的资源；不能用最新版 Swift 或新规则混入旧源码后，再将构建结果描述为原始旧版应用。需要原版窗口、原生程序或签名字节时，以对应 Release 附件为准。

## 安全查看旧版本

各版原 app 使用相同的主程序名、默认端口 `18473` 和 `~/Library/Application Support/FocusQuest`。直接打开旧 app 可能连到正在运行的最新版后台，也可能接触当前存档；它不是自动隔离的历史体验环境。

只查看代码不需要启动 app。想运行某版旧界面和后端时，在单独的临时数据目录和独立端口启动该版 `server.py`，并给它一个不存在的同步来源。以源码位于仓库原布局为例：

```sh
FQ_HISTORY_DIR="$(mktemp -d /private/tmp/focusquest-history.XXXXXX)"
/usr/bin/python3 outputs/focus-quest/server.py \
  --port 18490 \
  --data-dir "$FQ_HISTORY_DIR/data" \
  --source "$FQ_HISTORY_DIR/absent-source.json"
```

浏览器打开 `http://127.0.0.1:18490`。这个临时环境不会读取真实番茄文件或当前学习数据库；结束时在终端按 Ctrl+C。使用前确认所选历史版本的 `server.py --help` 提供这些参数。若要体验整个旧版原生 app，使用独立 macOS 用户或其它隔离环境，不把当前私人存档交给旧程序。

最新版自带的 `static/classic` 是初版风格的兼容界面，仍使用当前记录服务和当前奖励/目标规则；它不等同于整个 v1.0 原始程序。`static/classic/origin.json` 记录初版界面原始哈希，便于追溯。

## 个人存档的边界

版本标签、源码和原 app 都不含个人学习数据库、钱包、收藏、日历配置或番茄账号资料。这些被排除在 GitHub 备份之外。换机保留个人状态需要另存一致 SQLite 备份，方法见[换电脑恢复指南](换电脑恢复指南.md)。不要用旧版 app 打开已被新版更新的存档来尝试回滚。
