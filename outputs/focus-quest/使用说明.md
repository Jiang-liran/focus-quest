# 专注远征

## 1.49.15 · 随风而来的星岛特效

重新制作19款已购星岛特效，撤下统一的大图标、环圈和双光核，改用各题材的自然动态：花瓣与银杏翻转飘落，萤火在草木旁游动，蝴蝶扇翅迁飞，蒲公英与纸飞机随风穿过画面，气泡与小浮灯缓缓升起；流星短暂掠过天空，星云轻移、连星闪烁，露光贴近草木，雨纹与银色、彩色细流贴近地面。

主岛特效在独立天气层显示，不再被学习进度亮度与雾层压暗；用小粒子的亮度与完整运动路径增加可见性。雨夜城市室内只在真实窗外呈现，天台和俯瞰夜景的地面特效分别适配屋顶与河面。关闭动态会保留自然分散的静态位置，后台暂停；没有新增常驻计时器。默认原貌、已有收藏和价格保持原规则，各种装饰与主题可继续搭配。

## 1.49.14 · 更清楚的星岛特效

19款可装备的星岛特效在主岛和星辉城使用同一套分层场景绘制。增强关键图形的大小、清晰轮廓与光核，并加入各款对应的轨迹或环境结构；近景与远景形成层次，装备后无需放大场景也更容易辨认。草叶露光、萤火、花瓣、雪晶、流星、星云、纸翼、浮灯与连星等各有自己的形态和动态，雨夜城市仍保持安静的灯光氛围。

初旅星光保持原貌；已有购买、抽奖获得的星岛特效直接升级。装饰、时装、伙伴、进度条和界面主题继续独立搭配，图形不挡住岛屿、篝火、建筑或礼盒的点击。关闭动态时仍保留特效的静态轮廓，后台或进入其它场景时暂停动画；常规刷新不重新播放，无新增后台计时器。

交付目录中的 **「专注远征.zip」是已经验证的安装备份**，建议保留，供以后重新安装使用。

## 1.4.1 同一次专注只计一次

- 电脑完成的任务经手机再次写入日历后，软件会按任务名称与起止时间识别为同一次专注；分钟与秒的精度差异不会造成重复累计。
- 两个来源匹配时，统一使用番茄 ToDo 的有效专注分钟计算进度。例如电脑记录 1 分钟、日历跨度 1 分 16 秒，最终只计 1 分钟。计时中暂停造成的跨度差异，也不会覆盖电脑记录的有效分钟。
- 升级会自动合并旧版本已保存的明确重复记录，保留原任务身份和删除／恢复状态。多个相似候选或人工操作冲突时不猜测合并。
- 仅在日历中存在的手机记录仍按日历跨度计时；日后收到对应电脑记录时，更新同一条记录，不再交一次任务。

## 如何捕获记录

服务每 **3 秒**检查一次电脑番茄 ToDo 的本地记录文件，只导入已完成、时长有效的记录。计时尚未完成或尚未写入文件时，不会先增加进度。重复读取同一条记录不会重复累计；源记录修改后，可重新同步对应数据。

从 1.4 起，**来源删除会同步反映到学习统计**。电脑记录需要两次健康读取确认缺失；手机日历需要两份不同读取时间的有效快照确认缺失。确认后，记录进入回收站，不再计入时长、目标进度与导出。单条记录如果同时来自电脑和手机，要等两个已知来源都确认删除，才会自动移除。

日历删除只在当前所选日历、允许的任务名称、当前查询覆盖范围内核对（默认最近 90 天）。断网、权限错误、损坏或过期快照、换日历、超出查询范围，不会作为删除依据。手机删除通常需等待下一两次自动读取；点击「立即同步」也可请求新读取。

读取位置：`~/Library/Application Support/tomatodo/tomatodo_db.json`

这是一种独立的本地读取方式，不是番茄 ToDo 官方接口。应用**只读**该文件，不改写番茄任务、计时或账号设置，也不复制账号凭据。番茄 ToDo 未来升级如果改变文件格式，可能需要适配。

### iPhone 自动同步

已用真实计时验证：iPhone 番茄 ToDo 完成的「408做题」2 分钟，通过系统日历出现在 Mac 上，能够携带任务名和起止时间。手机需保持番茄 ToDo「我的 → 更多功能 → 写入系统日历」开启，并选择两端可同步的 iCloud 日历。本机当前使用你选择的 **「工作」iCloud 日历**。

Mac 的日历辅助程序每 30 秒检查一次所选日历，也响应日历变化；点击「立即同步」会另发一次读取请求。只输出与已知番茄任务名称完全一致、非全天且符合时长规则的事件；已经结束的事件用于归档，已开始但未结束的事件只用于等待提示，不保存普通日程和备注，不创建、修改或删除日历内容。不要在此日历中用相同番茄任务名创建普通日程，否则无法仅凭这些字段区分；日后可在番茄中改选专用学习日历，并同步更新本机配置。

收到的手机记录按日历中的起止时间差计时，正常 2 分钟样本已核对一致。暂停与恢复的计时是否与日历跨度一致尚未实测；若以后发现此类时长偏差，可以据实际样本调整。四个「复习」任务仍按听课分类，「做题」任务按做题分类。

**不用每次导出、传文件或保持专注远征窗口打开。** 当前用户登录 Mac 且电脑正常运行时，辅助程序会持续采集；iCloud 何时把新事件送到 Mac 不由本程序控制，因此不是保证即时同步。Mac 恢复运行后会补查最近 90 天仍在日历里的匹配记录。启用写入日历之前、番茄没有写入日历的历史记录，不会凭空出现，仍需一次性补录或导入。

日历访问由 macOS 授权给「专注日历诊断」辅助程序，该名称沿用先前已授权的应用。程序只读，但 macOS 对读取事件提供的系统权限名称为日历「完全访问」。如果系统撤销了授权，连接面板会显示错误，可打开辅助程序重新授权。手机记录先写入本机快照，再由专注远征存档，不连接番茄账号或索取密码。

为了避免重复累计，同一个日历事件使用稳定标识；若电脑与日历记录同名、开始和结束时间分别相差不超过 5 秒、时间区间有重叠，且双方都只有一个对应候选，则归为同一条。匹配不要求有效专注分钟等于日历跨度，统一以电脑记录的有效分钟和归档日期为准。无法确认的相似记录不会随意合并。已合并记录在两个来源均确认删除后进入回收站，手动删除／恢复仍按用户选择处理。

## 手动移除与恢复

在「专注档案」找到记录，点击该行「移除」即可放进回收站。这个操作只影响专注远征，不会改写番茄 ToDo 或日历，而且重复同步不会把手动移除的同一条记录重新加回来。

专注档案右上方的「回收站」显示已移除数量，可查看任务、原学习日期、时长和移除原因，并逐条恢复。恢复会把记录保留在本机统计中，后续来源缺失不会再次自动移除；不会把它重新写回番茄或日历。回收站内的记录不计入导出 CSV。

如果删除的是日历查询范围之外的更早历史记录，可用此处的「移除」处理。删除同步采用可恢复的方式，原始数据仍保留在数据库与备份中，没有永久清空入口。

## 科目归类

任务名称默认按照以下关键词归类：

| 科目 | 默认匹配 |
| --- | --- |
| 数学 | 数学 |
| 408 | 408、数据结构、操作系统、计组、计算机组成、计算机网络 |
| 政治 | 政治 |

无法识别的任务列为「待分类」。它们的时长仍计入每日总量和累计学习时长，但暂不计入四个科目的进度。可在设置中指定任务的科目，手动分类优先于名称关键词，并应用到同名历史记录。

1.37 起，四科目标由复盘页的司衡调整，每天最多两次；周目标首次填写后锁定。历史学习分钟数保留，完成百分比使用该日期归档的目标。缺少可靠历史目标的旧日期会明确标注，不能当作已核实的达标记录。

## 听课与做题统计

学习方式与科目分别归类。同一条记录可以同时属于「数学」和「听课」，不会额外增加总学习时长。统计模块展示所选日期的听课、做题及其他时长，并分别列出各科的分配。

任务名称默认按以下规则识别学习方式：

| 学习方式 | 默认匹配 |
| --- | --- |
| 听课 | 复习数学、复习408、复习政治、复习英语；以及名称中的听课、网课等听课关键词 |
| 做题 | 名称中的做题、刷题、习题、真题等做题关键词 |
| 其他 | 没有匹配到听课或做题规则的任务，例如背单词；同时包含两类关键词、无法确定方式的任务也暂列此类 |

根据你的确认，四个「复习」任务都按听课统计，**已有历史记录和以后新完成的同名记录都会生效**。在「远征设置」的任务归类中，可以为每个任务分别指定科目与学习方式；手动选择优先于默认关键词，并重新计算同名历史记录。

学习方式建议是简单的时长提醒：所选日期某科听课已达到 1 小时，而做题不足听课时长的一半时，会建议增加相应科目的练习。例如数学听课 2 小时、做题 20 分钟，会提示安排数学练习。它不判断课程内容或学习质量；当天目标已完成或时间较晚时，建议优先安排到下次学习，不要求当天额外加时。回看历史日期时，统计和建议都以所选日期的记录为准。

## 后台记录与登录启动

**本机已启用此功能**，后台服务指向 `~/Applications/专注远征.app`。关闭或退出界面不会删除记录，也不会停止后台采集。电脑关机或休眠期间不能轮询；恢复运行后会补读本地文件中仍然存在的完成记录。

以下命令留作以后重新安装、移动应用或重新启用服务时使用；当前无需重复执行。请先把「专注远征.app」放到准备长期保留的位置，再在终端运行：

```bash
bash macos/install-service.sh "/完整路径/专注远征.app"
```

上面命令需在本说明所在的 `focus-quest` 文件夹内运行。脚本注册当前用户的 `com.local.focusquest` LaunchAgent，不需要管理员权限；它指向该 .app 内的 `Contents/Resources/server.py`。重复安装会更新已有注册。移动或改名 .app 后，请重新运行脚本更新路径。

脚本会停止由同一 .app 启动的旧服务，再交由系统管理。如果端口 18473 被其他路径启动的服务占用，脚本会说明情况并退出，不会误停其他程序。

已注册登录服务时，应用会优先通过系统恢复该服务，再等待连接；不会为同一个服务另开一份采集进程。⌘R 会重新检查连接，按需恢复服务。

取消电脑记录的登录启动：

```bash
bash macos/uninstall-service.sh
```

此操作停止电脑记录后台服务，**保留全部学习数据**。再次打开 .app 时仍能手动启动本机服务。

手机日历由独立的 `com.local.focusquest.calendarbridge` 登录服务负责，安装与停止脚本位于旁边的「手机同步诊断」文件夹：`install-service.sh`、`uninstall-service.sh`。停止该服务会暂停手机新记录采集，已有学习存档保留。移动辅助 .app 后，应重新运行该文件夹中的安装脚本并传入新路径。升级辅助程序时，先停止旧后台，再打开新程序完成系统授权，最后启动或重启后台并退出辅助窗口；避免授权前启动的进程继续持有旧权限状态。主界面仍可正常关闭与打开。

## 导出、备份与数据位置

学习数据存放在 `~/Library/Application Support/FocusQuest/`，数据库为 `focus-quest.sqlite3`。应用菜单「窗口 → 打开数据文件夹」可直接打开该目录。日历配置为 `calendar-bridge-config.json`，只含所选日历 ID 与允许的任务名称；过滤后的最新快照为 `calendar-bridge-snapshot.json`，辅助服务日志为 `calendar-bridge.log`。所有统计在本机完成，服务只监听 `127.0.0.1:18473`。

运行服务时，在浏览器打开以下本机地址可以下载全部学习记录 CSV：

<http://127.0.0.1:18473/api/export>

CSV 便于使用表格软件查看；完整备份还应包含设置。请使用提供的备份脚本，它可以在服务运行时创建一致的数据库副本：

```bash
bash macos/backup-data.sh "/你选择的备份目录/专注远征备份.sqlite3"
```

脚本不会覆盖已有同名文件。不要只复制正在运行的 `focus-quest.sqlite3` 单个文件作为完整备份，因为最新内容可能仍在 SQLite 的 WAL 文件中。

卸载时先停止电脑记录和手机日历两个登录服务，再删除 .app 和交付的源码文件夹即可。学习数据不会随应用删除而消失；是否删除数据目录由你自行决定。

## 故障排查与重新打包

- 暂无新记录：先确认番茄 ToDo 已结束本段计时，并等待几秒；查看应用中的连接状态。
- 手机记录缺失：查看「学习记录同步」中的手机状态，并确认 Mac 日历里已经出现该条任务；手机需继续开启写入日历。日历里没有的旧记录不会由此通道导入。
- 应用连接失败：按 ⌘R 重试，并查看数据目录中的 `server.log`；登录服务日志为 `service.log`。
- 本机端口被占用：已有专注远征服务可被窗口复用；其他程序占用端口时，需要先解决冲突。
- 升级源码后：在本说明所在文件夹运行 `bash macos/build.sh`。脚本编译原生窗口，并将当前 `server.py` 和 `static/` 打包进交付目录中的 .app；需要本机 Xcode Command Line Tools。

这个版本使用本机 `/usr/bin/python3` 和标准库，不依赖在线服务。它记录实际完成的时间，保留学习成果与行动手记，不设休息或中断学习的惩罚。
